# Calculation Conformance Matrix

**Purpose:** a change-controlled, source-to-rule-to-code-to-test ledger for all authoritative scheduling and project-controls calculations. This document is internal engineering evidence, not customer-facing product content.

**Mandatory gate:** see Product Principles — Principle 1C. Rules without exact source/version, expected edge cases, independent semantic review, mapped regression tests and exact-head CI remain PARTIAL or BLOCKED/UNVERIFIED; they do not count as complete.
