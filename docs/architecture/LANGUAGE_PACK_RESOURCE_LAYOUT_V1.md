# Language Pack Resource Layout v1.0\n\nEvery language pack is a versioned artifact whose manifest points to deterministic resources.\n\n## Required resources\n- `translations.json` — stable translation keys.\n- `glossary.json` — controlled construction/project-controls terminology.\n- `help.json` — Smart Guide/help resources.\n- `reports.json` — report/print labels and templates metadata.\n\n## Optional resources\n- `voice/input` — speech recognition model.\n- `voice/output` — speech synthesis model.\n- `ai/offline` — local AI model.\n\n## Rules\n- UTF-8 JSON for deterministic text resources.\n- No resource may alter machine-readable project identifiers, enums or calculation values.\n- Resource paths are manifest-controlled and must resolve inside the pack.\n- Pack activation must load all required deterministic resources before activation is committed.\n- Failed resource loading must leave the previous active language unchanged.\n- UI language, terminology and AI/voice model versions are independently versioned but linked by compatibility metadata.
