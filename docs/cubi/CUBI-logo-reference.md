## Approved visual direction
- Brand: CUBI Platform
- Descriptor: Construction & Building Intelligence
- Tagline: Plan. Control. Build Smarter.
- Primary mark: geometric C-shaped / connected-cube construction mark.
- Core palette: deep navy, electric blue, cyan/teal, with restrained neutral tones.
- Required variants shown in the reference: full logo, icon-only, light app icon, dark app icon, light/dark versions, and usage across web, desktop, mobile, reports/print.

## Repository relationship
The single canonical implemented logo is `apps/web/public/cubi-platform-logo-primary.svg`. Every client and display context resolves to this exact file; no light/dark duplicate is maintained. Web, Desktop and Mobile reference this same family through their client brand contracts; clients must not fork or redraw the approved mark. This document records the supplied visual reference so the implementation can be reviewed against the approved direction.
