# CUBI Platform — Logo Direction (2026-10-05)

## Purpose
Candidate commercial identity for Issue #1101, registered from the current `main` baseline.

## Design intent
- **Construction:** isometric structural/cubic frame.
- **Project control / Gantt:** three stepped schedule bars and a connected timeline motif.
- **AI / intelligence:** connected nodes and signal path embedded inside the mark.
- **Software/platform:** geometric, scalable icon rather than a literal crane, helmet or building illustration.
- **Enterprise precision:** restrained blue/teal palette and technical wordmark.
- **Multilingual readiness:** horizontal lockup is independent from RTL/LTR page layout.

## Assets
- `apps/web/public/cubi-platform-logo-primary.svg` — light-background primary lockup.
- `apps/web/public/cubi-platform-logo-primary-dark.svg` — dark-background primary lockup.

## Scope
This commit registers the logo direction only. It does not alter Shared Core, CPM/P6, scheduling, EVM, resources/costs, database contracts, or other authoritative business logic.

## Acceptance note
The asset is a candidate commercial logo direction for Issue #1101. Homepage integration should consume the asset after visual acceptance; this commit intentionally avoids silently replacing an already integrated production mark.
