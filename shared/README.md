# Shared ConstructionPM Contracts

This directory is reserved for artifacts that must remain common to Web and Desktop.

## Includes
- API contracts and DTO schemas.
- Shared domain/calculation specifications.
- Versioned project schemas.
- Cross-client parity fixtures.
- Common validation and integration contracts.

## Rule
Anything placed here is authoritative for both clients. Client-specific UI code must not redefine shared business semantics.
