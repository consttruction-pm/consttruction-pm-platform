GET STARTED

Three steps to your first project

CUBI separates the public site from the authenticated workspace. Signing in is the only step that opens project data.

The path in

Each step is explicit, so you always know which environment and which project you are working in.

1. Sign in

Use your CUBI account. Failed attempts are throttled; a wrong password never opens a workspace.

2. Choose an environment

The selector shows Engineering and Enterprise only when your roles allow them.

3. Open a project

Choose a project you are a member of. The workspace opens scoped to that project.

If something is missing

Access is data, not guesswork. Each missing item has a named cause.

No project listed

Your account is not a member of any project yet. Ask a project owner to add you.

Enterprise disabled

Your account lacks an enterprise role. An administrator can grant it.

Need more detail

The Help Center explains the common cases and how to reach support.
