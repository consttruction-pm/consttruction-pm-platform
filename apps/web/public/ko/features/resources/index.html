가용성에 근거한 배정

공통 자원 기록에서 인력과 수단을 계획하고, 캘린더가 각 근무일의 근거를 보여줍니다.

공통 기록

자원과 배정은 일정, 원가와 같은 기록을 공유합니다.

자원 기록

사람, 팀, 수단을 프로젝트 전체에서 한 번만 정의합니다.

배정

기간과 부하를 명시해 자원을 활동에 배정합니다.

가용성

보이는 부하

과부하

평준화
