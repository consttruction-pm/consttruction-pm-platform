기능 · 프로젝트 통제

통제는 작업을 따릅니다

마일스톤, 상태, 조치를 일정에 연결해 통제 결정이 실제 프로젝트 데이터에 근거하도록 합니다.

한눈에 읽는 상태

상태, 마일스톤, 차이를 별도 스프레드시트 없이 함께 읽습니다.

마일스톤

일정 위에 배치하고 기준선 대비 달성을 추적합니다.

통합 상태

진척, 지연, 위험을 하나의 통제 보기로 모읍니다.

시정 조치

누가 언제 무엇을 하는지 대상 작업 링크와 함께 기록합니다.

사실로 판단

통제 기록은 그것을 만든 프로젝트 데이터와 연결됩니다.

설명되는 차이

계획과 실적을 비교하고 차이의 출처를 잃지 않습니다.

책임

조치는 서버에서 확인된 역할을 따릅니다.

이력

기록은 날짜와 함께 남아 과거 결정을 되짚을 수 있습니다.
