기능 · 원가

작업이 일어나는 곳의 원가

예산, 배정, 지출 약정이 같은 프로젝트 데이터를 공유하므로 원가를 나중에 다시 맞출 필요가 없습니다.

예산에서 세부로

예산은 활동과 자원에 연결된 비목으로 나뉩니다.

구조화된 예산

비목별로 예산을 배분하고 WBS에 연결합니다.

파생 원가

계획 원가는 배정과 입력한 단가에서 계산됩니다.

약정

확정된 지출과 단순 예상을 구분합니다.

모호함 없이 비교

계획, 약정, 실적은 같은 기준에서 비교 가능한 별도 계열입니다.

읽히는 차이

계획과 실적을 비교하고 차이의 이유를 남깁니다.

날짜별 이력

원가 기록은 날짜와 함께 남아 과거 결정을 설명합니다.

단일 통화

프로젝트는 명시된 기준 통화를 가집니다.
