기능 · 일정

팀이 신뢰하는 일정

WBS에서 활동까지 계획하고 캘린더와 관계를 명시하며, 진척을 저장된 기준선과 비교합니다.

세부보다 구조 먼저

WBS, 활동, 관계는 같은 프로젝트 기록을 공유하므로 구조와 세부가 분리되지 않습니다.

작업 분할 구조

산출물과 작업 패키지를 팀이 따라갈 수 있는 계층으로 정리합니다.

활동과 관계

실제 순서를 반영한 기간, 캘린더, 의존성으로 활동을 정의합니다.

캘린더와 근무시간

근무일, 휴일, 교대를 명시해 실제 근무시간으로 날짜를 계산합니다.

기준선과 진척

저장된 기준선과 날짜가 붙은 진척이 있으면 차이를 기억이 아니라 기록으로 설명할 수 있습니다.

기준선 저장

승인된 일정을 고정하고 실제 작업과 비교합니다.

날짜별 진척

기준일의 진척을 기록하고 갱신 이력을 남깁니다.

공유 보기

같은 기록이 표, 캘린더, 보고서에 반영됩니다.
