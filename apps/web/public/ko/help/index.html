지원

공식 도움말을 한곳에

문서는 실제 화면과 작업을 설명하고, 지원 창구는 계정에 대한 답이 필요할 때 사용합니다.

문서부터 시작

공식 문서는 일상 작업과 제품 개념을 다룹니다.

작업 안내

프로젝트, WBS, 보고서 작성 단계를 따릅니다.

개념

일정, 원가, 자원이 같은 데이터를 공유하는 방식을 이해합니다.

언어

문서는 공개된 제품 언어를 따릅니다.

지원에 문의

계정 질문이나 장애는 직접 문의가 가장 빠릅니다.

계정

계정 주소와 대상 환경을 알려 주십시오.

장애

화면, 동작, 발생 시점을 알려 주십시오.

보안

의심스러운 문제는 즉시 신고해 주십시오.
