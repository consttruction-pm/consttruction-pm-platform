플랫폼 · 연동

시스템을 복제하지 않고 데이터 교환

연동은 제품 인터페이스로 읽고 쓰며, 프로젝트는 단일 원천으로 남습니다.

명시적 인터페이스

교환은 데이터베이스 복사가 아니라 문서화된 입구를 통합니다.

프로젝트 API

프로젝트 데이터는 문서화된 인터페이스로 교환합니다.

가져오기와 내보내기

기준을 깨지 않고 프로젝트 구조를 주고받습니다.

식별

교환은 계정의 식별과 역할을 존중합니다.

두 번째 시스템 없음

연동은 병렬 스키마를 만들지 않으며 프로젝트는 하나로 유지됩니다.

단일 원천

교환 후에도 프로젝트가 기준입니다.

추적

교환은 이력에서 식별할 수 있습니다.

상담

연동 요구를 팀에 알려 주십시오.

연동 계획

사용 중인 시스템을 알려 주십시오.
