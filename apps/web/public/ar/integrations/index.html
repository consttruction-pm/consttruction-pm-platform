التكاملات

بيانات مشروع تتحرك مع مؤسستك

يعرض CUBI بيانات المشروع عبر واجهة HTTP ذات إصدار ويستورد ويصدّر الصيغ التي يتبادلها فريق المشروع. يحدد كل تكامل ما يحتاجه وما لا يفعله.

كيف تتحرك البيانات

التكاملات صريحة: قناة ومالك ونطاق. لا شيء يُزامن بصمت.

واجهة HTTP

واجهة مشروع ذات إصدار لقراءة وكتابة سجلات المشروع تحت أذونات الجلسة والمشروع نفسها.

الاستيراد والتصدير

تبادل الجداول وبيانات المشروع بالصيغ التي يتوقعها شركاؤك وعملاؤك.

المستندات والأدلة

أرفق مستندات المشروع بسجلاتها لترحل الأدلة مع البيانات.

ما يحتاجه التكامل

كل اتصال محدد بمستأجر ومشروع ويُصادَق عليه كأي عميل آخر.

المصادقة

تتبع معالجة الجلسات والبيانات نفس قواعد الهوية في مساحة العمل.

نطاق المشروع

يرى الاتصال فقط المشاريع المصرح بها لحسابه.

ضبط التغيير

تحمي الكتابات ذات الإصدار وفحوص المراجعة السجلات من الاستبدال الصامت.

خطط للتكامل

تحدث معنا عن أنظمتك.
