機能 · プロジェクト統制

統制は作業に従う

マイルストーン、状況、措置を計画につなぎ、統制の判断が実際のプロジェクトデータに基づくようにします。

一目で読める状況

状況、マイルストーン、乖離を並行した表計算なしで一緒に読みます。

マイルストーン

計画上に配置し、基準計画に対する達成を追います。

統合状況

進捗、遅延、リスクを一つの統制ビューに集めます。

是正措置

誰がいつ何をするかを、対象作業へのリンクとともに記録します。

事実で判断する

統制の記録は、それを生んだプロジェクトデータと結びつきます。

説明できる乖離

計画と実績を比較し、乖離の出所を失いません。

責任

措置はサーバーで確認された役割に従います。

履歴

記録は日付付きで残り、過去の判断をたどれます。

ワークスペースで状況とマイルストーンを確認します。
