実際のデータからのレポート

レポートは保存された場所で計画、コスト、資源を読み、公表した数字をたどれるようにします。

単一の情報源

レポートは表計算で再計算せず、記録されたデータを読みます。

進捗

明確な基準計画に対する完了作業を示します。

コスト

計画、コミット、実績を同じ基準で示します。

資源

割当から導いた実際の負荷を示します。

統制された共有

公表したレポートはデータの日付と範囲を保ちます。

範囲

対象プロジェクトと期間を明記します。

整合

数字はワークスペースの表示と一致します。

アクセス
