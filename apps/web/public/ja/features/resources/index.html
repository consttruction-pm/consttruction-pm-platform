機能 · 資源

稼働可能量に基づく割当

共通の資源記録から人と手段を計画し、カレンダーが各稼働日の根拠を示します。

共通の記録

資源と割当は、計画やコストと同じ記録を共有します。

資源記録

人、チーム、手段をプロジェクト全体で一度だけ定義します。

割当

期間と負荷を明示して、資源をアクティビティに割り当てます。

稼働可能量

資源カレンダーが実際に使える日を明らかにします。

見える負荷

負荷は手入力の合計ではなく、実際の割当から計算されます。

過負荷

能力を超えて従事している期間を見つけます。

平準化

割当を動かし、計画への影響を確認します。

コスト連携

割当が二重入力なしでコストに反映されます。
