機能 · スケジューリング

チームが信頼できる計画

WBS からアクティビティまで計画し、カレンダーと関係を明示し、進捗を保存した基準計画と比べます。

詳細より先に構造

WBS、アクティビティ、関係は同じプロジェクト記録を共有し、構造と詳細が分かれません。

作業分解構成

成果物と作業パッケージを、チームがたどれる階層に整理します。

アクティビティと関係

実際の順序を反映した期間、カレンダー、依存関係で定義します。

カレンダーと稼働時間

稼働日、休日、シフトを明示し、実稼働時間で日付を計算します。

基準計画と進捗

保存した基準計画と日付付き進捗があれば、乖離を記憶ではなく記録で説明できます。

基準計画の保存

承認済みの計画を固定し、実際の作業と比較します。

日付付き進捗

基準日に進捗を記録し、更新の履歴を残します。

共有される表示

同じ記録が表、カレンダー、レポートに反映されます。
