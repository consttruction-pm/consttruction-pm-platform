機能 · コスト

作業が起きる場所のコスト

予算、割当、支出コミットメントが同じプロジェクトデータを共有し、後からコストを組み立て直す必要がありません。

予算から詳細へ

予算はアクティビティと資源につながる費目に分解されます。

構造化予算

費目ごとに予算を配分し、WBS に結びつけます。

導出コスト

計画コストは割当と入力した単価から計算されます。

コミットメント

確定した支出と単なる見込みを区別します。

曖昧さなく比較

計画、コミット、実績は別々の系列として同じ基準で比較できます。

読める乖離

計画と実績を比較し、乖離の理由を残します。

日付付き履歴

コスト記録は日付付きで残り、過去の判断を説明できます。

単一通貨

プロジェクトは明示した基準通貨を持ちます。
