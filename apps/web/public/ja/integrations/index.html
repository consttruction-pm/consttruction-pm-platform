プラットフォーム · 連携

システムを複製せずデータを交換

連携は製品のインターフェースを通じて読み書きし、プロジェクトは唯一の情報源として残ります。

明示的なインターフェース

交換はデータベースの複製ではなく、文書化された入口を通ります。

プロジェクト API

プロジェクトデータは文書化されたインターフェースで交換します。

入出力

基準を壊さずにプロジェクト構造を入出力します。

識別

交換はアカウントの識別と役割を尊重します。

第二のシステムを作らない

連携は並行スキーマを作らず、プロジェクトは一つに保たれます。

単一の源

交換後もプロジェクトが基準です。

追跡

交換は履歴の中で識別できます。

相談

連携の要件をチームに伝えてください。
