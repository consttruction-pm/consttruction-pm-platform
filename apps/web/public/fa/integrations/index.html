یکپارچه‌سازی

داده پروژه‌ای که با سازمان شما حرکت می‌کند

کوبی داده پروژه را از طریق یک API نسخه‌دار HTTP ارائه می‌دهد و قالب‌هایی را که تیم‌های پروژه مبادله می‌کنند وارد و خارج می‌کند. هر یکپارچه‌سازی می‌گوید چه می‌خواهد و چه کاری نمی‌کند.

داده چگونه حرکت می‌کند

یکپارچه‌سازی صریح است: یک کانال، یک مالک و یک محدوده. هیچ چیز بی‌صدا همگام نمی‌شود.

API مبتنی بر HTTP

یک API نسخه‌دار برای خواندن و نوشتن رکوردهای پروژه با همان نشست و مجوزهای پروژه.

ورود و خروجی

زمان‌بندی و داده پروژه را در قالب‌هایی مبادله کنید که شرکا و کارفرمایان انتظار دارند.

اسناد و شواهد

اسناد پروژه را به رکوردهایی که پشتیبانی می‌کنند پیوست کنید تا شواهد همراه داده حرکت کند.

یک یکپارچه‌سازی چه می‌خواهد

هر اتصال به یک مستأجر و یک پروژه محدود است و مانند هر کلاینت دیگری احراز هویت می‌شود.

احراز هویت

مدیریت نشست و اعتبارنامه از همان قواعد هویتی فضای کاری پیروی می‌کند.

محدوده پروژه

یک اتصال فقط پروژه‌هایی را می‌بیند که حسابش برای آن‌ها مجاز است.

کنترل تغییر

نوشتن نسخه‌دار و بررسی ویرایش، رکوردها را از بازنویسی بی‌صدا محافظت می‌کند.

کوبی را روی پروژه خودتان ببینید

فضای کاری را باز کنید و از یک نمای یکپارچه پروژه ادامه دهید.
