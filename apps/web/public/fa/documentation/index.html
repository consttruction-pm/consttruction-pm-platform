مستندات

مستندات برای کاری که انجام می‌دهید

مجموعه مستندات از محصول پیروی می‌کند: محیط‌ها، راه‌اندازی پروژه، زمان‌بندی، کنترل‌ها و دسترسی به داده. هر راهنما می‌گوید برای کدام محیط است.

از اینجا شروع کنید

راهنمایی را انتخاب کنید که با نقش شما و محیطی که حسابتان می‌تواند باز کند هم‌خوان باشد.

شروع کار

وارد شوید، محیط را انتخاب کنید و پروژه‌ای را باز کنید که برای آن مجاز هستید.

محیط مهندسی

برنامه‌ریزی، زمان‌بندی، کنترل و گزارش‌گیری برای تیم‌های تحویل پروژه.

محیط سازمانی

دسترسی سازمانی، نقش‌ها و سطح وظایف برای حساب‌های مجاز.

مرجع

مواد مرجع برای مفاهیمی که محصول بر آن‌ها تکیه دارد.

داده و API

چگونه داده پروژه محدود، نسخه‌دار و از طریق API خوانده می‌شود.

امنیت و دسترسی

چگونه هویت، نشست، نقش و عضویت پروژه در کنار هم قرار می‌گیرند.

واژه‌نامه

اصطلاحات کنترل پروژه که کوبی به کار می‌برد، هر یک با یک تعریف.

کوبی را روی پروژه خودتان ببینید

فضای کاری را باز کنید و از یک نمای یکپارچه پروژه ادامه دهید.
