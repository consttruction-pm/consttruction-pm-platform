Возможности · Контроль проекта

Контроль следует за работой

Связывайте вехи, статус и меры с расписанием, чтобы решения контроля опирались на реальные данные проекта.

Статус понятен сразу

Статус, вехи и отклонения читаются вместе, без параллельной таблицы.

Вехи

Ставьте вехи на расписание и отслеживайте достижение относительно базового плана.

Сводный статус

Соберите прогресс, задержки и риски в одном представлении контроля.

Корректирующие меры

Фиксируйте, кто, что и когда делает, со ссылкой на работу.

Решать по фактам

Каждая запись контроля связана с проектными данными, которые её породили.

Объяснимое отклонение

Сравнивайте план и факт, не теряя источник отклонения.

Ответственность

Меры следуют ролям, проверенным на сервере.

История

Записи хранятся с датой, чтобы восстановить прошлое решение.
