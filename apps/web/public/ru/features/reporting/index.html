Возможности · Отчёты

Отчёты из реальных данных

Отчёты читают расписание, стоимость и ресурсы там, где они хранятся, поэтому опубликованная цифра остаётся прослеживаемой.

Единый источник

Отчёт не пересчитывает проект в таблице, а читает сохранённые данные.

Прогресс

Показывайте выполненную работу относительно понятного базового плана.

Стоимость

Показывайте план, обязательства и факт на одной базе.

Ресурсы

Показывайте реальную загрузку из назначений.

Управляемый обмен

Опубликованный отчёт сохраняет дату и охват своих данных.

Охват

Каждый отчёт указывает проект и период.

Согласованность

Цифры совпадают с тем, что показывает пространство.

Доступ

Отчёты проекта видят только разрешённые роли.
