FEATURES · AI ASSISTANCE

An assistant that reads your project context

The CUBI assistant works with the project you have open. It helps organise information and prepare summaries; you stay in control of every decision and every write.

Assistance, not autonomy

The assistant proposes and drafts. Creating, changing or approving a project record remains a user action.

Project context

Answers are grounded in the project the session is authorised for.

Summaries

Turn long project records into a summary you can review.

Navigation help

Find the window, record or definition you need instead of hunting through menus.

Visible and bounded

The assistant is a visible part of the workspace, bounded by the same permissions as the user.

Same permissions

The assistant never exceeds the access of the signed-in user.

Transparent actions

You see what is proposed before anything is written.

No hidden data paths

Assistance uses the project data and services the product already exposes.
