FEATURES · PROJECT CONTROLS

Controls that read the same plan

Project controls only work when they measure the plan the team actually executes. CUBI keeps status, milestones and indicators on the same project record.

One operating view

Milestones, status and indicators are derived from the schedule rather than maintained in a parallel spreadsheet.

Milestones

Track contractual and internal milestones against the activities that drive them.

Schedule status

See where the plan stands today against the baseline, by project and by work package.

Performance indicators

Review indicators built on the same dates and progress the team records.

Decisions with evidence

Each control point links back to the activities, documents and records that explain it.

Decision log

Keep the reasoning behind a schedule or cost decision close to the record it changed.

Thresholds and alerts

Define the thresholds that matter and surface them before they become surprises.

Reporting

Produce reports from the same data the workspace uses, not from a re-keyed copy.
