INTEGRATIONS

Project data that moves with your organisation

CUBI exposes project data through a versioned HTTP API and imports and exports the formats project teams exchange. Each integration states what it needs and what it does not do.

How data moves

Integrations are explicit: a channel, an owner and a scope. Nothing is synchronised silently.

HTTP API

A versioned project API for reading and writing project records under the same session and project permissions.

Import and export

Exchange schedules and project data in the formats your partners and clients expect.

Documents and evidence

Attach project documents to the records they support so the evidence travels with the data.

What an integration needs

Every connection is scoped to a tenant and a project, and is authenticated like any other client.

Authentication

Session and credential handling follow the same identity rules as the workspace.

Project scope

A connection sees only the projects its account is authorised for.

Change control

Versioned writes and revision checks protect records from silent overwrites.
