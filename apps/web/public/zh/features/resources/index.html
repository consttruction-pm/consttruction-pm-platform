与计划相连的资源需求

资源、角色与分配属于需要它们的活动，因此需求与可用性来自团队执行的同一份进度计划。

从角色到分配

先定义工作需要什么，再分配给能够交付的人员与设备。

资源与角色

人员、设备与角色存放在所有项目共享的目录中。

分配

按工作需要把资源以数量和工期挂到活动上。

可用性

同时查看需求与可用性，而不是事后核对两套系统。

面向现实规划

分配数据跟随活动日历，已批准的日历变更会更新其资源需求。

感知日历

按真实工作时间而不是名义天数计算资源需求。

角色覆盖

在发布进度计划前发现超负荷的角色。

与成本相连

把分配带入成本视图，无需第二次录入。
