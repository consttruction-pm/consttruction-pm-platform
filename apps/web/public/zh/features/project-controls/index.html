功能 · 项目控制

依据同一份计划的控制

项目控制只有衡量团队真正执行的计划才有意义。CUBI 让状态、里程碑与指标共享同一项目记录。

统一的运营视图

里程碑、状态与指标由进度计划推导，而不是在并行的电子表格中维护。

里程碑

对照驱动里程碑的活动，跟踪合同与内部里程碑。

进度状态

按项目和工包查看当前计划相对基准的位置。

绩效指标

基于团队记录的同一组日期与进度审阅指标。

有据可依的决策

每个控制点都回指解释它的活动、文档与记录。

决策记录

把进度或成本决策的理由放在它所改变的记录旁边。

阈值与提醒

定义真正重要的阈值，在问题演变为意外之前呈现。

报表

用工作区同一份数据生成报表，而不是重新录入的副本。
