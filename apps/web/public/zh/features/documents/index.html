记录与工作相伴

只有当文档能从它所说明的活动出发被找到时才有用。CUBI 把记录与证据保留在项目情境中。

单一项目记录

文档与合同挂在所属项目、工包或活动上。

项目文档

存储并查找项目所依赖的图纸、报审与记录。

合同

把合同信息放在它所约束的进度与成本记录旁边。

证据

附上支持进度、成本或决策的证据。

可查且可问责

每份记录保留其责任人与历史，让团队清楚自己看到的是什么。

责任归属

记录文档的上传者与时间，并保留项目范围。

版本意识

让文档情境保持可见，避免依据已被取代的版本行事。

访问边界

文档访问与其他工作区一样，遵循项目成员关系。
