安全

清晰说明的安全

本页描述产品今天实际做了什么。它不是认证声明，也不能替代对您自身部署的安全评审。

身份与会话

访问始于已认证的账户和服务器端会话。

密码处理

密码以加盐 scrypt 哈希存储，绝不保存明文。

会话处理

会话使用 HttpOnly Cookie，并对变更状态的请求提供 CSRF 防护。

登录限速

连续登录失败会被限速，以减缓凭据猜测。

数据边界

项目数据按租户与项目隔离，并在服务器端强制执行。

租户与项目范围

每次项目读写都限定于账户的租户与成员关系。

基于角色的访问

环境与操作访问遵循服务器校验的角色，而非客户端显示的按钮。

公开与私有界面

营销页面为静态；项目记录仅由已认证运行时提供。
