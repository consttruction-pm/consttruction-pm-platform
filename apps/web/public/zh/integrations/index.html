集成

随组织流动的项目数据

CUBI 通过版本化 HTTP API 提供项目数据，并导入导出项目团队交换的格式。每项集成都会说明所需条件与边界。

数据如何流动

集成是明确的：一条通道、一个责任人、一个范围。不会有静默同步。

HTTP API

版本化项目 API，在相同会话与项目权限下读写项目记录。

导入与导出

以合作伙伴与客户期望的格式交换进度与项目数据。

文档与证据

把项目文档挂到其支持的记录上，让证据随数据同行。

集成需要什么

每个连接限定于一个租户和一个项目，并像其他客户端一样认证。

认证

会话与凭据处理遵循与工作区相同的身份规则。

项目范围

连接只能看到其账户获授权的项目。

变更控制

版本化写入与修订校验防止记录被静默覆盖。
