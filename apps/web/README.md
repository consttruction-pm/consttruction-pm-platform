# ConstructionPM Web Application

This directory is reserved for the Website/Web Application client.

## Contract
- Uses the shared API/Application contracts.
- No direct database access.
- No independent scheduling/progress/EVM/resource/cost calculations.
- Must support Persian/English and Jalali/Gregorian presentation.
- Must respect permissions and ProjectContext.
- Must preserve typed values.

## Feature parity
Business capabilities must match the Desktop Application. Platform-specific UI/interaction differences are allowed; business semantics are not.

## Ownership
Primary client implementation: User/Product Client Track.
Backend/API contracts: Hasan.
